# 완성작 이미지

`public/images/` 폴더에 이미지 파일을 넣으면 커뮤니티·마이페이지에서 표시됩니다.

파일명은 **공백 없이** `completed_` 접두사와 동일해야 합니다.

- `completed_cherry.jpg` — 초보자용 체리 키링
- `completed_muffler_rainbow.jpg` — 파스텔 무지개 스카프 / 도안 없음 기본 이미지
- `completed_bear.jpg` — 곰돌이 인형 몸통 도안
- `completed_beenie_grey.jpg` — 겨울 털모자 기본형
- `completed_heart.png` — 미니 하트 코스터
- `completed_gloves_white.jpg` — 포근한 화이트 장갑
- `completed_star.jpg` — 분홍 별 코스터
- `completed_socks.jpg` — 포근한 분홍 양말
- `completed_beenie_yellow.jpg` — 노란 비니 모자
- `completed_Beige cardigan.jpg` — 베이지 가디건
