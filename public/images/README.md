# 완성작 이미지

`public/images/` 폴더에 PNG 파일을 넣으면 커뮤니티·마이페이지에서 표시됩니다.

파일명은 **공백 없이** 아래 규칙과 동일해야 합니다.

## 예시 파일명

- `그림1_완성작_베이지색가디건.PNG`
- `그림1_완성작_체리키링.PNG`
- `그림2_완성작_목도리.PNG`
- `그림2_완성작_무지개스카프.PNG`

HTML 예시:

```html
<img src="그림1_완성작_베이지색가디건.PNG" alt="완성작" />
```

(실제 경로: `/images/그림1_완성작_베이지색가디건.PNG`)
